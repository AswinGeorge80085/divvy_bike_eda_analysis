
# Divvy Bikes EDA Project

## Project Overview
This project analyzes Divvy bike trip data to understand customer behavior and ride usage patterns.

## Objectives
- Compare casual riders and members
- Identify popular bike types
- Analyze ride timing trends
- Study trip duration patterns
